# Niranjan AI Studio — Free Offline Android project

Open in Android Studio (JDK 17, Android SDK 35), allow Gradle sync, then Build > Build APK(s). APK is generated under `app/build/outputs/apk/debug/`.

Working: offline Android TTS Hindi/English preview (depending on installed system voice), pitch/speed, WAV synthesis to app-specific Music directory, offline original text poster generator with PNG saved to Pictures/NiranjanAIStudio, local prompt library. No paid API or subscription.

NOT included: generative AI image/video/music engines, recorded-voice transformation, MP3 conversion, cloud storage, automatic copyright clearance. Those need additional models/services and rights review. WAV export location may require a file manager that can access Android app-specific storage. Test on a real Android device before distribution.
